# DevLog AI Discord 봇 (미니 버전)

DevLog AI를 웹 대시보드 없이 디스코드 슬래시 커맨드만으로 쓸 수 있게 하는 미니 봇 —
프로젝트 등록 같은 초기 세팅부터 오늘의 TODO/업무일지/보고서 확인까지 디스코드에서 처리한다.
DevLog AI 백엔드(`http://localhost:3000`)가 켜져 있어야 동작한다.

명령어가 많아 보여도 실제 최상위 명령어는 9개뿐이고, 관련 동작은 서브커맨드로 묶여 있다
(`/todo view`, `/todo add`처럼). `/help`를 치면 전체 목록을 볼 수 있고, 각 명령어를 입력할 때도
디스코드가 하위 옵션/설명을 자동으로 보여준다.

## 명령어

### 오늘의 업무
- `/todo` — 오늘 할 일 + AI 추천 목록을 보여준다. 프로젝트 선택/완료 처리/추천 추가는 드롭다운으로, 새 할 일 등록은 "➕ 할 일 추가" 버튼 → 제목 한 줄만 입력하는 팝업으로 처리한다 (프로젝트는 지금 보고 있는 필터를 그대로 따름, 우선순위/마감일은 기본값).
- `/worklog` — 가장 최근 업무일지 요약을 보여준다.
- `/summary` — 오늘의 요약 카드(연속 활동일, 수정 파일 수, 커밋 수, 세션 수, 에러 수, 업무일지 수)를 보여준다. 프로젝트 선택 드롭다운 지원.
- `/heatmap` — 최근 18주 활동 히트맵을 음영 블록(`·░▒▓█`)으로 보여준다. 프로젝트 선택 드롭다운 지원.
- `/report` — 가장 최근에 생성된 기간 보고서 그룹을 보여준다. "이번 주/지난 주/이번 달/지난 달 생성" 버튼으로 바로 생성(전체 프로젝트 대상), "직접 입력" 버튼을 누르면 시작일/종료일만 입력하는 팝업이 뜬다.

### 프로젝트 / 설정 (초기 세팅)
- `/project add name:<이름> path:<경로>` — 로컬 git 저장소를 프로젝트로 등록 (커넥터 등록+초기 동기화까지 자동).
- `/project discover [path:<상위폴더>]` — 그 폴더 아래(최대 2단계)에서 등록 안 된 git 저장소를 찾아 드롭다운으로 보여주고, 선택한 것들을 즉시 등록. path를 생략하면 기존 프로젝트가 모여있는 폴더를 자동으로 추측해서 씀.
- `/project list` — 등록된 프로젝트 전체 목록과 상태를 본다.
- `/project archive project:<이름>` — 프로젝트를 비활성화/재활성화(토글)한다.
- `/project delete project:<이름>` — 프로젝트를 완전히 삭제한다 (버튼으로 한 번 더 확인).
- `/sync` — 모든 git 커넥터를 지금 바로 동기화하고 상태(정상/에러)를 본다.
- `/settings autodraft [enabled] [time] [days]` — 자동 업무일지 초안 생성 스케줄을 보거나 바꾼다.

### 기타
- `/help` — 전체 명령어 목록을 요약해서 보여준다.

## 설정

1. `.env.example`을 `.env`로 복사하고 값을 채운다.
   - `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`는 [Discord Developer Portal](https://discord.com/developers/applications)에서 발급.
   - `DISCORD_GUILD_ID`를 채우면 그 서버에만 즉시 등록되고(테스트용), 비워두면 전역 등록(반영까지 최대 1시간).
2. 의존성 설치 및 빌드:
   ```bash
   npm install
   npm run build
   ```
3. 슬래시 커맨드 등록 (커맨드를 추가/수정할 때마다 한 번씩 다시 실행):
   ```bash
   npm run deploy-commands
   ```
4. 봇 실행:
   ```bash
   npm start
   ```
